# Hyprland Lofi — KiloCode handoff

This package contains a ready-to-paste prompt for KiloCode CLI.

## Files

- `KILOCODE_PROMPT.md` — full project context + first task.
- `palette.qml.txt` — canonical lofi palette reference.
- `workspace.qml.txt` — current workspace component reference.

## Suggested use

From the root of your Quickshell/Hyprland config repository, start KiloCode CLI and paste the contents of `KILOCODE_PROMPT.md`.

The prompt intentionally tells the agent to inspect the existing project first instead of blindly replacing files.
